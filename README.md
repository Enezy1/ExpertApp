# نظام جلسات الخبراء (ExpertApp)

تطبيق سطح مكتب لويندوز لإدارة ملفات القضايا والأ，专家اء — وزارة العدل — الكويت.

يجمع مستندات القضية، يقرأ المحاضر والحكم والصحيفة، يحلّل سجل الحركة
(`ECS_CASE_FLOW`)، ويولّد تقرير القضية بصيغة Word من قالب «المحضر» المعتمد.

---

## ⬇️ التحميل (للمستخدم النهائي)

**النسخة الحالية: 1.2.8**

⬇️ [تحميل مثبّت نظام جلسات الخبراء (EXE — 205 م.ب)](https://github.com/Mohammad-Alenezi/ExpertApp/releases/latest/download/تثبيت_نظام_جلسات_الخبراء.exe)

> الرابط فوق **ثابت** — يشير دائماً لآخر نسخة منشورة.
> إذا تعطّل، افتح صفحة [الإصدارات](https://github.com/Mohammad-Alenezi/ExpertApp/releases)
> وحمّل الملف `تثبيت_نظام_جلسات_الخبراء.exe`.

### خطوات التثبيت

1. حمّل ملف الـ EXE من الرابط أعلاه.
2. شغّله (ويندوز قد يسألك «allow to run» — اختر **Run anyway**).
3. المعالج يتكفّل بالباقي تلقائياً:
   - تثبيت **Visual C++ Redistributable** إن كان ناقصاً (بدونه ينهار البرنامج صامتاً).
   - تثبيت **Microsoft Edge WebView2 Runtime** إن كان ناقصاً (لازم لنافذة تسجيل الدخول).
   - اختصار على سطح المكتب + قائمة ابدأ + برنامج إلغاء تثبيت رسمي بلوحة التحكم.
4. شغّل «نظام جلسات الخبراء» من سطح المكتب، وسجّل الدخول بحساب ministry.

## 🧩 شو يسوي البرنامج

- **ملف القضية** — مجلد لكل قضية ببنية موحّدة (`_نظام/`) فيها العقود والوقائع والمحاضر والتقرير.
- **الجلسات** — يسحب الجلسات من نظام الوزارة، ويميّز نوعها (**فتح محضر** / **جلسة محكمة**) من *سجل الحركة* مو من اللون.
- **الموضوع والإجراءات** — يولّد نص الموضوع والإجراءات والصياغة القانونية من مصادر القضية، مع اعتماد الخبير.
- **البحث** — بحث في الاجتهادات مدعوم بالاقتباس الحرفي ورقم المرجع.
- **التقرير Word** — يُبنى من قالب `ma7dar_template.dotx` المعتمد (محضر أعمال).
- **الإحصائيات** — تقرير HTML لإحصاء عدد القضايا على فترات.
- **الذكاء الاصطناعي** — Gemini / Groq / OpenRouter / OCR خارجي، بمفاتيح اختيارية لكل خبير (مشفّرة بـDPAPI).

## 🛠️ البناء من المصدر

```powershell
# 1) المتطلبات
pip install -r requirements.txt   # إن توفّر — أو ثبّت الحزم يدوياً من ExpertApp.spec

# 2) اختبارات (لازم كلها ناجحة قبل أي بناء)
python -W ignore -m unittest discover -p "test_*.py"

# 3) بناء EXE (PyInstaller) — يرفع رقم النسخة تلقائياً
python build.py             # patch
python build.py --minor     # minor
python build.py --major     # major

# 4) بناء المثبّت (Inno Setup 6)
"C:\Program Files (x86)\Inno Setup 6\ISCC.exe" Installer.iss
# الناتج: installer_output\تثبيت_نظام_جلسات_الخبراء.exe
```

> **ملاحظة للبناء:** `Installer.iss` يحتاج ملفَّي `vc_redist.x64.exe` و
> `MicrosoftEdgeWebview2Setup.exe` بجانبه. هما **مو بالريبو** (حجم + ترخيص) —
> نزّلهم من الروابط الرسمية المذكورة في تعليقات `Installer.iss`.

## 📁 بنية المشروع

| المسار | شنو فيه |
|---|---|
| `main.py` | نقطة الدخول — تركيب الرقع (مهلات الشبكة، عقد البيانات) |
| `api.py` | الاتصال بنظام الوزارة: القضايا، الجلسات، سجل الحركة |
| `case_*.py` | منطق القضية (المFacts، الإجراءات، الموضوع، البحث، التقارير) |
| `qt_*.py` | واجهة PyQt6 (الصفحات، البطاقات، النوافذ) |
| `report_v3.py` | تركيب التقرير النهائي (Word) |
| `doc_router.py` | توجيه المستندات وتوزيعها على الخطوات |
| `case_schema.py` | عقد بيانات `case.json` — فحص وإصلاح |
| `net_timeouts.py` | جدول مهلات طلبات نظام الوزارة |
| `Installer.iss` / `ExpertApp.spec` | بناء المثبّت والـ EXE |
| `test_*.py` | اختبارات وحدة لكل موديول (~1100 اختبار) |

التفاصيل الكاملة: [`PROJECT_MAP.md`](PROJECT_MAP.md) و[`PROJECT_MEMORY.md`](PROJECT_MEMORY.md) و[`CLAUDE.md`](CLAUDE.md).

## 🔐 ملاحظات أمنية (مهم)

المستودع **ما يحتوي** على:

- 🔑 `gemini_network.ini` — فيه مفاتيح API نصية (مستثناة بالكامل).
- 🗄️ `ExpretDB.mdb` — قاعدة بيانات القسم الحقيقية (قضايا حقيقية).
- 📁 `test_data/A2263973/` و`samples/` — نسخة مجمّدة من قضية حقيقية بأسماء أطراف.
- 📦 مجلدات `قديم/` و`محذوفه/` و`build/` و`dist/` و`installer_output/`.

لو نسخت المشروع عندك، انسخ `gemini_network.ini` **يدوياً** من جهازك — أو أضف مفاتيحك من
شاشة الإعدادات (تُخزَّن مشفّرة بـDPAPI على جهازك فقط).

**اختبار `test_report_v3.RealCaseTests` يتخطّى نفسه تلقائياً** على أي نسخة ما فيها
مجلد `test_data/A2263973/` — ما يكسر الحزمة.
